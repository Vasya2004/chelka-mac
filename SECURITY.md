# Security Policy

## Reporting a Vulnerability

Please report security issues privately through GitHub's
["Report a vulnerability"](https://github.com/Vasya2004/chelka-mac/security/advisories/new)
form of this repository instead of opening a public issue.

Chelka listens only on `127.0.0.1` (loopback). It never reads your Claude/Codex login tokens.
Issues in the upstream Boring Notch code can also be reported to
[TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch).
